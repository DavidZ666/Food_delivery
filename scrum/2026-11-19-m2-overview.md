## Discussion

### Reviewing individual contributions

The team went through the work that each member had added to the project during Milestone 2. Everyone explained the features they worked on, the changes they made, and how their contributions fit into the overall application. The team also reviewed the different pull requests and changes that had been added to the GitHub repository.

### System integration

The team reviewed how all the different parts of the application worked together. This included customer accounts, restaurant and menu functionality, shopping carts, checkout, and order creation. The main goal was to make sure the different features connected properly instead of only working as separate parts of the system.

### Testing and bug fixes

The team discussed the testing that had been completed and went over any issues that came up during development. The team checked that important operations worked correctly, including adding menu items to a cart, updating quantities, calculating totals, and creating orders through checkout. Any remaining problems were discussed so they could be addressed before the deadline.

### Final review and documentation

The team reviewed the overall project and checked that the work completed during M2 was properly added to GitHub. This included looking over the README, API documentation, tests, and other required documentation. The team also discussed preparing for the final demonstration and making sure everyone could explain their own contributions.

- Review everyone's contributions to make sure all completed work was included in the project.
