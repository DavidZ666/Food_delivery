# M2 Planning Meeting Minutes

- **Date:** November 19, 2026
- **Team:** ByteBites
- **Topic:** M2 requirements, task breakdown, and system integration

## Discussion

### M2 task breakdown

The team discussed the requirements for Milestone 2 and broke down the remaining work into Epics, User Stories (US), and Tasks. The main focus was expanding the existing M1 functionality by connecting customer accounts, restaurant menus, shopping carts, checkout, and orders into one working system.

### Role requirements

The team discussed the functionality needed by different users, including customers and restaurant managers. This included customer registration and login, managing customer information, browsing restaurants and menus, adding items to carts, and completing checkout.

### System integration and data flow

The team discussed how the different parts of the application would communicate with each other. The goal was to make sure that information could move properly between the customer, restaurant, menu, cart, checkout, and order systems without duplicating data or breaking existing functionality.

### Task assignments

The team reviewed the remaining work and discussed which tasks each member would focus on. Members were able to choose tasks based on their interests and the areas that still needed development.

## Decisions

- Organize M2 work into Epics, User Stories, and Tasks.
- Focus on integrating the existing M1 functionality with the new customer, cart, checkout, and order features.
- Allow team members to choose and complete tasks based on their interests and availability.
- Make sure the different services and repositories communicate properly.
- Test the integrated functionality and fix any issues found during development.
